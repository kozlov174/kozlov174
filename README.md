## 🏆 Проекты

**AgroExchange — Система поддержки принятия решений для агросектора**  
- **Суть:** Сбор, обработка и систематизация данных внешних рынков рапса для корректировки экспортной цены.  
- **Роль:** ML + DevOps  
- **Стек:** Linux, Docker, Jenkins, Python, PostgreSQL  

**Проход — Система автоматизированной выдачи разовых пропусков**  
- **Суть:** Ускорение бизнес-процесса за счёт веб-сервиса и внутренних проверок, заменяющих бумажный документооборот.  
- **Роль:** Backend + DevOps  
- **Стек:** Linux, Docker, Kubernetes, Ansible, Terraform, Python, Grafana, Prometheus  

**Библиотека №14, Екатеринбург — Цифровая система**  
- **Суть:** Автоматизация взаимодействия читателей и персонала, замена бумажного читательского билета.  
- **Роль:** PM + Backend + DevOps  
- **Стек:** Python, Linux, Docker
